# Data Source Matrix

Documentation checked on 2026-09-01. Provider terms and entitlements can change; adapters report runtime capabilities and never assume entitlement.

| Source | Interface / data | Auth / tier | Latency and limits | Main fields | Use | Limitations / license |
|---|---|---|---|---|---|---|
| [AlgoX Flow](https://algoxflow.com/api-docs) | `GET /api/gexmap?ticker=` | No key; free | Gamma cached about 15m; poll no faster than refresh | spot, flip, walls, max pain, expected move, ATM IV, strike GEX | Free Validation structure; Production cross-check | Missing OI/Greeks stay null and lower confidence. AlgoX alone is not Production-complete. |
| [GammaGrid](https://github.com/gammagrid/gammagrid) | Self-hosted v0.4+ Postgres `option_snapshots`; legacy SQLite read boundary | No provider key beyond its upstream source; open source | Scheduled/periodic snapshots, not streaming | chain, computed Greeks, GEX, walls, flip, max pain, OI, IV | Production Paper structure only when freshness and coverage thresholds pass | Uses unofficial Yahoo access by default with no SLA; dealer GEX is an estimate. Adapter is read-only and source-scoped. |
| [FINRA OTC Transparency](https://www.finra.org/filing-reporting/otc-transparency/otc-transparency-data-api) | Query API, including weekly summary; public files | Some datasets require API registration; public/non-commercial access varies | Daily/weekly/monthly; delayed aggregate | ATS/non-ATS/OTC volume and short-sale aggregates | Context and Shadow/post-trade features | Not real-time dark-pool tape. FINRA notes short-sale volume is not short interest and is incomplete without exchange data. Terms vary by commercial use. |
| [Alpaca Market Data](https://docs.alpaca.markets/us/docs/historical-api) | `/v2/stocks/bars`, quotes, snapshots; options under `/v1beta1` | Key/secret; free and paid entitlements | Feed-dependent; IEX is partial, SIP/OPRA entitlement-dependent | OHLCV, quotes, trades, option chain/snapshots | Price trigger if current entitlement supplies fresh data | [Indicative options trades are delayed 15m](https://docs.alpaca.markets/us/docs/historical-option-data); OPRA is paid/entitled. This project never calls trading endpoints. |
| [Unusual Whales API](https://unusualwhales.com/public-api) | REST/WebSocket/Kafka; options flow, GEX, dark pool, market data | Bearer API key; paid/trial plan dependent | Real-time products and rate limits are plan-dependent | trade-side flow, sweeps/blocks, exposure, dark-pool prints | Optional Production sensor if entitlement, timestamp and freshness pass | Exchange licensing and redistribution restrictions must be reviewed for the account. No key is required for the service to run. |
| [Quant Data API](https://quantdata.us/api/docs/introduction) | POST tools: order flow, exposure-by-strike, heat map, OI change, equity prints, dark flow, stock price | Bearer `QUANTDATA_API_KEY`; paid and OPRA agreement for relevant data | [240 requests/60s and 20/s burst](https://quantdata.us/api/docs/rate-limiting), but clients must honor headers | consolidated flow, GEX/DEX, OI delta, equity prints, dark-flow buckets, OHLC | Optional Production sensor when entitled/fresh | Aggregated dark flow is not per-print tape. Exchange license and redistribution rules apply. |
| yfinance / Yahoo | Unofficial intraday OHLCV | No key; free | Availability and delay vary; no SLA | completed 5m bars, price, volume | Free Validation candle source only | Always labeled unofficial and limited; never Production-eligible. |
| Alpha Vantage | Intraday OHLCV REST | Optional free key | Free-tier rate limits; local request guard enforced | completed 5m OHLCV | Optional Free Validation backup | Not required; quote latency/entitlement remains non-authoritative for Production. |
| Finnhub | Quote/news/calendar context | Optional free key | Endpoint and free-tier limits vary | quote and context metadata | Optional context only | Never required for reclaim candles. |
| Manual macro YAML | Local validated YAML | None | Operator-maintained | CPI, FOMC, NFP, PPI, PCE, GDP, speakers, auctions, expiries, holidays and closes | Guard after manual approval | Production approval requires the YAML approval flags and verified core-event coverage. Unknown calendars are tagged explicitly. |
| Deterministic demo fixture | Local JSON generated by the service | None | Static | complete synthetic ticker maps and bars | Research/QA only | Never eligible for Production Paper. Clearly labeled synthetic. |
